## 0. 一言でいうと

**百年散歩**は、100年以上続く老舗と伝統工芸を日本語・英語で紹介し、外国人観光客にも実際に訪ねてもらうためのWebサイト。
現在は**サイト本体（読むだけの静的ページ）**が世界公開されており、その裏方として**取材ノート（運営者だけが使う記録アプリ）**が手元で動いている。

## 2. 動く場所

| | 動く場所 | URL | 止まるか |
|---|---|---|---|
| **公開サイト** | **GitHubのサーバー**（GitHub Pages） | https://iwasegiken.github.io/hyakunen-sanpo-practice/ | 止まらない。PCの電源とは無関係 |

### 公開サイトが世界に出るまで

```
手元のPC  ──git push──▶  GitHub  ──自動──▶  GitHub Pages  ──▶  世界のブラウザ
（E:ドライブ）              （保管庫）        （HTMLを配るだけ）
```

GitHub Pagesは**HTMLをそのまま配るだけ**でプログラムは動かさない。だから無料で、だから運営ツール（Python）は載せられない。

## 3. データの保存先

| データ | 中身 | 場所 | 形式 |
|---|---|---|---|
| **取材記録** | お店の名前・種類・創業年・店主名・掲載許諾・許諾日・続いてきた理由・公式サイト・撮影メモ・備考 | `streamlit/data/shops.json` | JSON（テキスト） |
| **利用者** | お名前・塩(salt)・変換結果(hash) | `streamlit/data/users.json` | JSON |

- データベースは**使っていない**。ファイル1つにまとめて読み書きしている（現在1件）
- 記録1件ずつに**見えない8桁のID**を付けてある。同じ名前のお店が2つあっても取り違えない
- 保存は**一時ファイルに書いてから置き換える**方式。途中で失敗しても元のファイルは無傷

## 4. どう守っているか

| 守り | 中身 |
|---|---|
| **通信の暗号化** | 公開サイトは **HTTPS**（GitHub Pagesが自動で提供）。運営ツールは手元のみなので通信そのものが外に出ない |
| **ログイン** | 運営ツールは**お名前＋合言葉**。合言葉は**保存しない**。人ごとに違う「塩(salt)」を混ぜて SHA-256 で一方通行に変換し、**塩と変換結果だけ**を保存 |
| **自分のデータだけ** | 記録には「書いた人」が入り、一覧は自分のものだけ。**画面で隠すだけでなく、書き換え・削除の処理側でも持ち主を確認**している |
| **入力の扱い** | 入力された文字はHTMLの「命令」にならないよう `< > & "` を置き換えてから表示（XSS対策）。長さの上限を超えたら赤字で理由を出す |
| **秘密をGitに出さない** | `.gitignore` で `streamlit/data/` を除外。取材データも合言葉のハッシュもGitHubには行かない |
| **壊れたときに黙らない** | データが読めないときは「0件」ではなく**理由とファイルの場所を画面に出す** |

### ⚠️ 守りの弱点（正直に書く）

- **合言葉の変換は学習用**。SHA-256 + salt は、総当たり攻撃に対して弱い。本番で公開するなら **bcrypt / Argon2** へ作り直す必要がある
- **HTTPSは公開サイトのみ**。運営ツールを外に出すなら別途必要
- **利用者は2人分の登録があるだけ**で、権限の区別（管理者/一般）は無い

## 5. どう公開・更新しているか

```
① 手元で直す（VS Code / Claude Code）
② git add -A → git commit -m "何をしたか"
③ git push
④ GitHubが受け取り、GitHub Pages が自動で世界へ反映（約10秒〜1分）
```

- **検索には出ない**。全ページに `<meta name="robots" content="noindex, nofollow">` を入れてあるため、URLを知っている人だけが見られる
- リポジトリは **Public**（GitHub Pagesの無料枠の条件）。ただし中身に個人情報は入っていない
- 写真・紹介文がそろったら `noindex` を外して検索にも載せる予定

## 6. 弱点と注意（第42課題②）

### テスト

**自動テストが1つも無い。** 直すたびに手で確認している。
食器洗いサポートには241件のテストがCIで動いているが、百年散歩にはまだ無い。
→ 第50課題（テストを書く）で着手予定。

### 個人情報の扱い

取材ノートには**店主のお名前・掲載許諾の状況・未公開の取材内容**が入る。

- Gitに入れない（`.gitignore`）
- バックアップ先は自分のPCと自分の別PC。クラウドには置いていない
- **お問い合わせ機能は未実装**。作ればメールアドレスを預かることになるので、その時点で扱いを決め直す必要がある

### 著作権・ライセンス

| | |
|---|---|
| 写真 | **まだ1枚も載せていない。** 他サイト（食べログ等）からの転用は禁止。自分で撮るか、お店から提供を受けたものだけを使う方針 |
| 掲載許諾 | 地蔵羊羹本舗さんは**ご本人から直接いただいた**（2026-09-10）。記録にも残している |
| 書体 | Google Fonts（商用利用可）。判子の書体は**暫定で Yuji Boku**。本命の**白舟古印体**は **2026年11月1日から無料配布開始**（冬・年賀状セット）＝**あと約5週間**。配布が始まったら差し替える。Webでの画像利用は規約1〜7項で認められている（確認済み） |
| このリポジトリ自体 | ライセンス表記なし。**Publicだが自由利用を許諾したわけではない**（要検討） |

### AIの利用料

- 開発は **Claude Code**（岩瀬様の契約）で行っている。**アプリ自体はAIを呼んでいない**ので、動かすだけなら費用ゼロ
- 将来、紹介文の英訳や下書きにAI APIを組み込む場合は、呼ぶたびに費用が発生する。その時は使用量の記録が必要
